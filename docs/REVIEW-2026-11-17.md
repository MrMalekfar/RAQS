# External review fixes — 2026-11-17

The external review used `main` at `f73c69e`, also tagged `v0.1.0`. Measurements in this historical record used Linux, Python 3.11 and pinned dependencies. Current cross-platform acceptance results are recorded in the [test guide](../tests/README.md#verified-review-branches-2026-11-19).

## Default temporal solver tolerances

Undeclared `numerics.temporal_ode` previously used QuTiP `rtol=1e-6`, `atol=1e-8`, while NUM-TD-001 rejects Hermiticity error above `1e-9`. Valid `lab006/experimental_near_resonant.json` cases at 0.4 V/m or IF=2 MHz were sporadically rejected.

The new undeclared defaults are `rtol=1e-10`, `atol=1e-12`, `nsteps=5000`, matching `examples/num_ode002`. Receipts report `temporal_ode.source = "raqs_certified_defaults"`. `utils/density_validation.py`, NUM-TD-001 thresholds and explicitly declared profile controls retain their contracts. Existing `test_num_ode002_profile.py` checks profile precedence.

A 30-case amplitude/phase/IF sweep had five rejections at `1e-8/1e-10` and none at `1e-10/1e-12`, with about 25% more solver time. A 16-case CLI sweep over 0.2–1.5 V/m and 0.5–2 MHz passed every case. Undeclared time traces shift by about `3e-7`, at the scale of the previous integration error.

## Sub-grid DoA peak refinement

Phase beamforming, Bartlett, MVDR/Capon and MUSIC previously returned a scan angle, giving -30.0° for a -30.4° arrival on a 1° grid. `doa/peak_refinement.py` uses the analytic derivative and a bracketed root solve to locate a stationary point of the same `m(θ)ᴴ A m(θ)` form between neighboring grid points, preserving the steering convention.

`DOAResult.azimuth_deg` is refined. Diagnostics retain `grid_azimuth_deg` and `peak_refined`, and reports retain `sensing.estimated_aoa_grid_deg` and `sensing.doa_peak_refined`. `refine_peak=False` selects the original grid estimate. A missing bracket or a candidate without improvement retains the grid peak.

`tests/test_doa_peak_refinement.py` adds 44 checks. Six off-grid angles across four estimators have ideal plane-wave error below `1e-6°`. For 300 random noisy MUSIC arrivals, RMSE is 0.068° refined and 0.293° grid-only, compared with `1°/√12 ≈ 0.289°`. The real ARC/BDF/DoA chain recovers a -30.4° target within `1e-3°` while reporting grid -30.0°. Ideal on-grid inputs stay exactly on the grid.

## Adaptive Doppler integration performance

The Liouvillian is affine in the two optical detunings. `DetuningAffineSteadyState` builds it once and uses a small dense trace-constrained solve per velocity, with the same NUM-SS-001 certification. At each scan point, the first two velocities are compared with reference results at tolerance `1e-12`. A build problem or disagreement disables the kernel for the remaining spectrum. It is enabled for adaptive integration with the direct backend and no Hamiltonian noise model.

`tests/test_doppler_affine_kernel.py` checks direct-solver parity over 200 detunings at `≤1e-13`, profile-spectrum parity at `≤1e-12`, and reference fallback for an intentionally corrupted kernel.

## Thesis wording and remaining scope

The DoA result checks phase preservation in simulation. Data generation and estimation use the same plane-wave/steering model. Agreement establishes that the atomic pipeline preserves relative path phase under those assumptions. Experimental validation requires independent measurements. State the Doppler configuration for each reported result.

Worker reuse, `pyproject.toml` and bulk print/import cleanup remain outside this patch. Laser linewidth is compared independently, with the main profile default retained.
