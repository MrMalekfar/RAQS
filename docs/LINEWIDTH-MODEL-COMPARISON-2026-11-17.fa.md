# مقایسهٔ دو مدل پهنای خط لیزر — ۲۰۲۶-۱۱-۱۷

این PR فقط مقایسه است. **پیش‌فرض پروفایل‌ها، schema و مسیر اجرای اصلی تغییر نکرده‌اند.**
این شاخه روی شاخهٔ اصلاحات بازبینی (`review-fixes`) ساخته شده است، چون به اصلاح زیرشبکه‌ای
DoA و تلرانس‌های پیش‌فرض جدید نیاز دارد تا اختلاف‌های کوچک دیده شوند.

## دو مدل

- **مدل فعلی (per-level):** پهنای خط probe و coupling هر کدام در بودجهٔ dephasing یک تراز
  می‌نشیند: `[g_probe, g_coupling, g_rf] + collision`، یعنی `√g_k |k⟩⟨k|` روی ترازهای ۲، ۳ و ۴.
- **مدل پخش فاز میدان:** پهنای خط probe و coupling **فقط یک بار** و از راه تابع موجود
  `create_laser_phase_diffusion_ops` وارد می‌شود (فاز probe روی ترازهای ۲ تا ۴، فاز coupling
  روی ترازهای ۳ و ۴). در بودجهٔ per-level فقط سهم غیرنوری می‌ماند: برخورد و پهنای خط RF.

اثر روی همدوسی‌ها (`g = 2π·FWHM`؛ `tests/test_linewidth_model_comparison.py`):

| همدوسی | مدل فعلی | پخش فاز میدان |
|---|---|---|
| ρ₁₂ | g_probe/2 | g_probe/2 |
| ρ₁₃ (همدوسی تاریک EIT) | g_coupling/2 | (g_probe + g_coupling)/2 |
| ρ₂₃ | (g_probe + g_coupling)/2 | g_coupling/2 |
| ρ₃₄ | g_coupling/2 | ۰ |

## روش

اسکریپت `rydberg_aoa/scripts/compare_linewidth_models.py`:

1. خط لولهٔ دست‌نخورده با پهنای خط موردنظر اجرا می‌شود؛ این نتیجهٔ مدل فعلی است.
2. همان خط لوله با پهنای خط نوری صفر اجرا و فراخوانی‌های دقیق حل‌گر آن (طیف و taskهای
   sensing) ثبت می‌شود. این فراخوانی‌ها فقط بودجهٔ برخورد/RF را دارند.
3. همان فراخوانی‌ها با عملگرهای پخش فاز میدان، از راه seam رسمی نویز
   (`simulation/noise_seam.py`)، دوباره اجرا می‌شوند. چیز دیگری فرق نمی‌کند.

کنترل درستی: بازاجرای فراخوانی‌های خودِ گام ۱ بدون مدل نویز باید آرایه‌های خط لوله را
بازتولید کند. در همهٔ حالت‌های زیر خطای این بازاجرا برای طیف و IF دقیقاً صفر بود.

```
python -m rydberg_aoa.scripts.compare_linewidth_models \
    --profile examples/lab007/prescribed_full.json \
    --fwhm-mhz profile 0.5 --output-dir out/linewidth
```

## نتیجه‌ها

پروفایل‌ها: `examples/lab007/prescribed_full.json` و `experimental_full.json`، با اسکن ۴۱ نقطه‌ای
`±10 MHz` فقط برای این مقایسه. طیف با Doppler تطبیقی و خروجی IF بدون Doppler است (طبق خود
پروفایل). هر دو پروفایل اعداد یکسان دادند. داده‌های کامل در `docs/linewidth_comparison/`.

پهنای خط پروفایل: `linewidth_rates_per_us = [0.006283, 0.006283, 0]`، یعنی FWHM برابر ۱ kHz برای
probe و coupling. همهٔ مثال‌هایی که پهنای خط را روشن کرده‌اند همین مقدار را دارند.

| کمیت | ۱ kHz (پروفایل) — فعلی | ۱ kHz — پخش فاز | ۰٫۵ MHz — فعلی | ۰٫۵ MHz — پخش فاز |
|---|---|---|---|---|
| قلهٔ عبور EIT، RF خاموش | 0.87661 | 0.87658 | 0.85937 | 0.84944 |
| عبور در مرکز، RF روشن | 0.74520 | 0.74520 | 0.73800 | 0.74224 |
| بیشینهٔ اختلاف عبور (RF خاموش / روشن) | — | `2.3e-5` / `4.0e-5` | — | `9.9e-3` / `1.5e-2` |
| نسبت دامنهٔ IF (پخش فاز / فعلی) | — | 1.00025 | — | 1.0867 |
| جابه‌جایی فاز مشترک IF | — | `0.0003°` | — | `0.183°` |
| خطای فاز نسبی مسیر ۲ و ۳ | `‎-0.000199°`، `‎-0.000051°` | `‎-0.000199°`، `‎-0.000051°` | `‎-0.000203°`، `‎-0.000049°` | `‎-0.000172°`، `‎-0.000042°` |
| برآورد زاویه (phase beamforming، هدف `‎-30°`) | `‎-30.0000374°` | `‎-30.0000374°` | `‎-30.0000359°` | `‎-30.0000309°` |

برآورد زاویه در این جدول برای هر دو مدل با phase beamforming گرفته شده تا فقط مدل اتمی
فرق کند؛ برآوردگر خودِ پروفایل `experimental` (MUSIC) در فایل JSON جدا ثبت شده است.

## برداشت

- **در پهنای خط پروفایل‌های فعلی (۱ kHz) دو مدل عملاً یکی‌اند:** اختلاف عبور کمتر از `4e-5`،
  دامنهٔ IF حدود ۰٫۰۲۵٪، و زاویه بدون تغییر.
- **در ۰٫۵ MHz اختلاف دیده می‌شود:** قلهٔ EIT حدود ۰٫۰۱ کمتر شفاف است، دامنهٔ IF حدود ۸٫۷٪
  بزرگ‌تر است و فاز مشترک `0.18°` جابه‌جا می‌شود.
- **زاویهٔ برآوردشده در هر دو حالت به انتخاب مدل حساس نیست** (اختلاف کمتر از `1e-5°`)، چون
  تغییر دامنه و فاز بین مسیرها مشترک است.

## محدودیت‌ها

- مدل پخش فاز، نویز فاز سفید و مستقل دو لیزر را فرض می‌کند؛ نویز همبسته یا دامنه را ندارد.
- پهنای خط RF در هر دو مدل روی تراز ۴ می‌ماند.
- مقایسه برای taskهای sensing ساده است: بدون Doppler زمانی، بدون تحقق نویز RF و بدون
  readout فیزیکی. برای پروفایل‌هایی با این موارد، اسکریپت با خطا متوقف می‌شود.
- طیف مدل پخش فاز از مسیر مرجع (بدون کرنل سریع) حل می‌شود، چون مدل نویز فعال است.
