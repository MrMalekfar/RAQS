# آزمون‌های فعال

این مجموعه به کد، پروفایل‌ها و baselineهای همین نسخه وابسته است. خروجی اجرای قبلی، پوشهٔ منابع شخصی یا ابزارهای آرشیوی پیش‌نیاز آن نیست. دادهٔ مصنوعی در آزمون فقط قرارداد مصرف‌کننده را می‌سنجد؛ اثبات مقداردهی یا صحت علمی مدل نیست.

آزمون‌های پژوهش‌های بازنشسته در این نسخه نیستند؛ مقایسهٔ تعداد آزمون با snapshot تاریخی بدون توجه به این تغییر دامنه درست نیست. [راهنمای آزمون](../docs/usage.md) و [قواعد توسعه](../AGENTS.md) را ببینید.
