# پروفایل‌های نمونه

فایل‌های JSON این پوشه برای مثال‌های مسیر اصلی و آزمون‌های فعال انتخاب شده‌اند. برای شروع از `lab006/` و برای پیکربندی کامل‌تر از `lab007/` استفاده کنید. `noise*/` نمونه‌های نویز و مطالعه، `dop*/` نمونه‌های Doppler و `num_ode002/` کنترل‌های عددی را نگه می‌دارند. `atom*/`، `literature001/` و `relax002/` به قراردادهای گونهٔ اتمی، نمونه‌های ادبیات و نرخ‌های واپاشی مربوط‌اند.

فایل‌های design و شواهد ممیزی قدیمی که به آرشیو پژوهشی وابسته بودند انتخاب نشده‌اند. `literature001/manifest.json` دادهٔ ثابتِ مورد استفادهٔ آزمون فعال است. [راهنمای اجرا](../docs/usage.md) شیوهٔ مصرف نمونه‌ها را توضیح می‌دهد.
